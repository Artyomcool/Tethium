# Ввод, очередь и внимание к сессиям — 2 ноября 2026

Кандидат: `build/desktop-composer-final-20261102/Tethium/Tethium.exe`.

Изменения:

- Ctrl+C/X/V сохранены при добавлении обработчика изображений; Ctrl+Z и Ctrl+Shift+Z работают в текущем черновике. Загрузка другого черновика очищает undo, чтобы не переносить текст между сессиями.
- PNG из буфера сохраняется без уменьшения и потери alpha, миниатюры находятся над полем. Список вложений хранится в SQLite и передаётся при замене окна. Codex получает `localImage`, история — ссылку на исходный файл. Поведение Nimbalyst 0.82.4 исследовано в установленном `app.asar` без изменения приложения.
- Действия очереди раскрываются через ⋯ / правый клик. Удаление требует подтверждения. Отправленный элемент выделяется, части отображаются как `[N]`.
- Ctrl/Shift выбирает несоседние строки для склейки. Разбиение восстанавливает исходные строки и положение относительно невыбранных. Границы отправок и происхождение поручений хранятся отдельно от текстового разделителя.
- Стоп останавливает текущую сессию и потомков, оставляя очереди на паузе. «Перебить» сохраняет приоритетную правку и начинает её после остановки всей этой группы. Повтор того же requestId не прерывает уже начатую правку. Независимые сессии продолжают работу.
- Отдельная точка: незакрытый вопрос или непросмотренное завершение. Прочтение фиксируется только для видимого конца выбранной сессии в активном окне. Старая отметка прочтения не скрывает новое завершение.
- Квота читается раз в 5 минут. Вращается существующая кнопка; время чтения рядом, без дополнительной строки и изменения высоты панели.
- Для встроенного Chromium синхронизированы native/AWT focus owner; возврат в composer проверен настоящими кликами и клавиатурой. Каждый GUI получает собственный root cache, чтобы новый процесс при reload не перенаправлялся в старый. Подход к фокусу сверён с [примером самого JCEF](https://github.com/chromiumembedded/java-cef/blob/master/java/tests/detailed/MainFrame.java).
- На рабочем столе установлен ярлык с медузой. Launcher читает `desktop-active.json`, активирует живое окно через IPC или запускает текущую сборку.
- [256 вариантов иконки](../design/icon-exploration-v2/index.html), две генерации, реальные alpha-атласы и манифест нарезки. Все элементы проверены на светлой и тёмной контактных сетках. Это варианты для выбора, текущая медуза сохранена.
