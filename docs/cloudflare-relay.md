# Cloudflare relay Tethium

`tethium-link.<account>.workers.dev` — общий транспорт Tethium и приложений проектов. Он не публикует локальные HTTP-порты: ноутбук и телефон сами открывают по исходящему WebSocket, а Worker только сводит две стороны одной комнаты.

## Выбор пути

- При первой LAN-привязке Android сохраняет IP-префикс сети без SSID и разрешения на геолокацию.
- В этом префиксе используется только прямой TCP/HTTP к ноутбуку. Cloudflare не является аварийным обходом домашней сети.
- В мобильной или другой Wi-Fi сети используется `wss://…workers.dev`.
- Вызовы проектных приложений через `content://dev.tethium.mobile.link` автоматически следуют тому же выбору. AH подключается обычным `.tethium/service.json` и `TethiumLink.java`; собственный Cloudflare Worker ему не нужен.

## Ключи

Для каждого привязанного телефона ноутбук создаёт отдельные 256 бит. Из них HMAC-SHA256 выводятся имя Durable Object, пароль комнаты и ключ AES-256-GCM. Сам ключ шифрования Worker не получает.

Секрет `GATEWAY_ADMISSION` хранится в Cloudflare и локальном `mobile/relay.json`. Ноутбук выдаёт телефону только HMAC-билет `room + role`, поэтому содержимое настроек телефона не позволяет создавать произвольные комнаты. Durable Object сохраняет пароль при первом подключении роли host и затем принимает только совпадающие стороны.

## Трафик и Free

`TrafficLedger` хранит агрегаты без URL и имён файлов: LAN/Cloudflare, вверх/вниз, подключения и число relay-сообщений за сутки UTC и за всё время. Экран «Подключение» показывает байты и консервативную оценку обоих дневных лимитов:

- Workers: одно начальное Upgrade = один запрос, WebSocket-сообщения не считаются;
- Durable Objects: подключения плюс входящие сообщения с коэффициентом 20:1;
- WebSocket Hibernation API не держит объект оплачиваемо активным во время простоя.

На 90 000 из 100 000 оценочных запросов relay перестаёт подключаться до следующего дня UTC. Это оставляет запас для проверок состояния и неавторизованных запросов, которых локальный счётчик не видит.

## Большие данные

- Изображения в чате вне LAN сначала запрашиваются как JPEG-превью до 320 px; оригинал загружается по нажатию.
- Тело запроса или ответа больше 1 МБ получает HTTP 428 без передачи тела. Повтор разрешается только с `X-Tethium-Approve-Large: true` после явного действия пользователя.
- APK вне LAN никогда не скачивается фоновым автообновлением и всегда требует нажатия, независимо от размера.
- HTTP проектных сервисов мультиплексируется бинарными порциями по 256 КиБ через тот же E2E-канал; base64 не используется.
