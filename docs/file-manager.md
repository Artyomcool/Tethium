# Файлы между устройствами Tethium

На компьютере: меню `⋯` над проектами → **Файлы…**. Экран есть и в полном
Tethium, и в лёгком Tethium Remote. На Android: меню → **Файлы**.

На Android файловый менеджер открывается отдельным окном с собственной карточкой
«Tethium · Файлы» в списке недавних приложений. Чат остаётся в своём окне.
Системный Back и жест назад ведут в родительскую папку, в том числе из ярлыка
проекта или папки пользователя на диск. В корне диска первое нажатие показывает
подсказку, второе в течение двух секунд закрывает окно. Кнопка `×` закрывает его
из любой папки. При выходе во время передачи запрашивается подтверждение.
По папкам можно перемещаться, пока передача продолжается.

Экран показывает всю файловую систему рабочего ноутбука: в списке сверху есть
**Диск C:** и остальные доступные диски, **Папка пользователя**, каталоги проектов
и **Полученные файлы** (`%LOCALAPPDATA%/Tethium/received`). Операции выполняются с
правами пользователя, под которым работает Tethium. В полном desktop-клиенте
кнопка **Общая папка…** добавляет любой выбранный каталог для обмена с привязанными
устройствами. Удалённый клиент не может сам добавлять такие каталоги.

* **Телефон → ноутбук:** «Отправить…», выбрать один или несколько файлов системным
  проводником Android. Файлы попадут в открытую папку ноутбука.
* **Ноутбук → телефон:** открыть файл в списке, «Сохранить на телефон…», выбрать
  место системным диалогом. Папка скачивается как ZIP.
* **Ноутбук → ноутбук:** подключить Tethium Remote существующей ссылкой привязки,
  открыть «Файлы…». «Отправить…» читает файлы и папки на клиентской машине;
  «Сохранить…» записывает выбранное на неё. Папки отправляются с сохранением
  структуры и скачиваются ZIP-архивами. При объединении папок отдельно
  подтверждается замена совпадающих файлов.

В списке есть создание папки, переименование и удаление с подтверждением.
Удаление физическое; непустая папка не удаляется. Корневую общую папку нельзя
переименовать или удалить этим API. Символические ссылки не передаются; при
создании ZIP они пропускаются.

Передачи идут порциями по 1 МиБ отдельными HTTP-запросами, не через поток чата.
Видны прогресс и кнопка остановки. Повторная отправка того же файла в ту же папку
продолжает незавершённую передачу, в том числе после перезапуска ядра. Скачивание
также продолжает локальный временный файл. На Android сначала используется кэш
приложения, затем проверенный файл копируется в выбранный документ: для больших
файлов нужно свободное место под эту промежуточную копию.

SHA-256 проверяется перед завершением. На ноутбуке загрузка записывается во
временный файл рядом с назначением и публикуется атомарно после проверки.
Для замены требуется версия существующего файла: если его успел изменить агент
или другой клиент, замена отклоняется и её нужно подтвердить снова.

Авторизация общая с существующей привязкой устройств. Файловые операции разрешены
внутри выбранного диска или каталога с проверкой реального пути. Для доступа к
файлам за пределами проекта выбирайте диск или папку пользователя в списке сверху.
Чтение и запись используют относительные пути внутри выбранного корня. Добавление общей папки
доступно через административный loopback API на рабочем ноутбуке.

Это использует действующее LAN-подключение Tethium. Интернет-туннель Cloudflare и
сквозное шифрование из обсуждения сети в эту поставку не входят.

Служебные записи лежат в `%LOCALAPPDATA%/Tethium/file-manager`. ZIP-снимки удаляются
после успешного сохранения клиентом; брошенные снимки старше недели убираются
при следующем старте ядра. Незавершённые загрузки на ноутбук остаются для
продолжения и скрыты в списке под именами `.tethium-transfer-*.part`.
