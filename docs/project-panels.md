# Интерактивная панель проекта

Проект публикует `.tethium/panel.json`. Tethium обнаруживает его без перезапуска
и добавляет строку панели под проектом. Выбор строки открывает панель на всю
рабочую область. В сессии того же проекта панель доступна в «Результатах» рядом
с чатом; кнопка разворачивания открывает её на весь экран.

Панель не является сессией, не создаёт историю и не запускает агента. Название
и интерфейс определяет проект. Маленькие SVG-виджеты продолжают работать отдельно.

## HTML без сервиса

```json
{"version":1,"title":"Обзор проекта","entry":"panel/index.html"}
```

`entry` разрешается относительно `.tethium/`, должен вести к HTML внутри проекта.
CSS, JavaScript, изображения и данные размещаются рядом с HTML. Они обслуживаются
существующим ArtifactServer с отдельным origin; внешние ресурсы и произвольный
доступ к файлам заблокированы. Браузер поддерживает canvas/WebGL.

## Интерфейс с вычислениями и редактированием

```json
{"version":1,"title":"CADabro · 3D / Groovy","url":"http://127.0.0.1:17761/panel/index.html"}
```

`url` указывает на HTTP(S) сервис проекта на loopback с явным портом. Он сам
обслуживает интерфейс и API на одном origin. Авторизацию, сохранение, конфликты
редактирования и вычисления реализует проект. Tethium не передаёт странице свой
токен и не предоставляет универсальный JavaScript-доступ к ядру.

Сервис может выбрать свободный порт и атомарно переписать манифест. Если URL
содержит случайный ключ доступа, манифест следует исключить из Git. Процесс
запускается средствами проекта; агент регистрирует его через `process_track`.
Tethium не исполняет команды из манифеста и не перезапускает сервис самостоятельно.
После перезапуска сервиса новый URL подхватывается автоматически.

`{"disabled":true}` скрывает панель; удаление манифеста делает то же самое.
Ошибки манифеста показываются внутри панели. Изменение файлов страницы
загружается кнопкой «Обновить», чтобы обновление метрик не уничтожало ввод.

Первая версия доступна в локальном desktop-клиенте. Android и удалённый desktop
не открывают локальные URL проектов: для них ещё нужен отдельный канал проксирования.

## CADabro

В `C:/git/CADabro/tools/start_tethium_panel.ps1` находится запуск проекта.
Сервис использует настоящий Groovy/CADabro runtime в отдельном JVM-процессе.
Панель содержит выбор модели, редактор, сохранение черновика, явное сохранение
с проверкой версии файла, пересчёт и WebGL-просмотр геометрии.
Рендер черновика не записывает исходник. Несохранённые черновики лежат
в `.local/tethium-panel/drafts.json` проекта и переживают закрытие GUI.
